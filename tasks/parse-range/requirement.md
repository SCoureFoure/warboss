Write a function `parseRange(spec)` that takes a string describing a set of
integers as a comma-separated list of ranges and returns a sorted array of the
integers in that set.

Each element of the comma-separated list is either a single integer or a range
written as `start-end`.

For example, `"1-3,5,8-10"` returns `[1, 2, 3, 5, 8, 9, 10]`.
